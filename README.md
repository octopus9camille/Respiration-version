# Respiration — versions publiées

Ce dépôt public contient uniquement :

- `version.json` : la dernière version disponible, lue par le bouton « Rechercher une mise à jour » de l'application ;
- les APK signés, dans les [Releases](https://github.com/octopus9camille/Respiration-version/releases).

Pour installer : télécharger `Respiration-vX.Y.Z.apk` depuis la dernière Release, l'ouvrir sur le téléphone et autoriser « Installer des applications inconnues ». Ensuite, les mises à jour passent par **Réglages → Rechercher une mise à jour**.

Aucune donnée n'est envoyée par l'application : elle lit seulement ce fichier public.
